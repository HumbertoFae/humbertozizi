# humbertozizi

Portfólio pessoal de Humberto Zizi — projetos, experiências digitais, sites,
aplicativos e ferramentas desenvolvidas com criatividade e tecnologia.

## Desenvolvimento local

Requer Node.js `>=22.13.0`.

```bash
npm install
npm run dev
```

## Builds

```bash
npm run build
npm run build:pages
```

O primeiro comando mantém o build original do Sites. O segundo gera a versão
estática usada pelo GitHub Pages.
